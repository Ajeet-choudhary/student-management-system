# Student Management System

A lightweight, responsive web application built to manage student academic records, track total enrollment, and calculate real-time average CGPA.

## Live Demo
[View Live Project](https://ajeet-choudhary.github.io/student-management-system/)

## Key Features
- **Add & Delete Records:** Manage student details including Roll Number, Name, Course, and CGPA.
- **Real-Time Search:** Instantly filter students by name or roll number.
- **Dynamic Dashboard:** Automatically updates Total Students and Average CGPA.
- **Persistent Storage:** Uses browser `localStorage` so data remains saved after page refresh.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Storage:** Browser LocalStorage API
- **Deployment:** GitHub Pages
